# PlanPop — Demo Script

Three end-to-end flows demonstrating the full feature set. Each takes about 60 seconds.

---

## Flow 1: Wedding (Aisha & Rohan)

1. **Home** — Click "Wedding" event-type card.
2. **Wizard Step 1** — "Wedding" is pre-selected. Click Next.
3. **Wizard Step 2** — Enter:
   - Name: `Aisha & Rohan`
   - Date: 6 months from today
   - City: `Mumbai`
   - Guests: `200`
   - Budget: `₹15,00,000`
4. **Wizard Step 3** — Select vibes: _Elegant_, _Traditional_; dietary: _Vegetarian_. Click "Generate Plan".
5. **Plan page loads** — Show:
   - **Dashboard**: countdown, budget/timeline/vendor health.
   - **Budget**: 6–8 categories summing to ₹15,00,000 exactly. Edit "Venue" amount to trigger overspend warning. SVG bar chart updates.
   - **Timeline**: milestones back-scheduled from the wedding date. Check one as done; note overdue styling on past items. Click a Google Calendar link.
   - **Vendors**: status cycling (To Find → Contacted → Booked). Click a Google Maps link for a vendor.
   - **Ideas**: themed suggestions. Click "Regenerate" on a category.
   - **Chat**: Type "Can we add a mehendi night?" → see streaming reply and optional JSON patch → Accept/Reject.
   - **Export**: Copy Markdown, Download JSON, Print.
6. **Persistence** — Refresh the page; plan reloads from localStorage.
7. **Dark mode** — Toggle theme; verify all sections render correctly.

## Flow 2: Birthday (Kiaan 7th)

1. **Home** → click "Birthday".
2. **Wizard** — Enter:
   - Name: `Kiaan 7th Birthday`
   - Date: 3 weeks from today
   - City: `Bangalore`
   - Guests: `30`
   - Budget: `₹50,000`
   - Vibes: _Fun_, _Colourful_
3. **Plan page** — Verify:
   - Budget categories are smaller/fewer (age-appropriate).
   - Timeline milestones fit the 3-week window.
   - Ideas include kid-friendly activities.
4. **Download ICS** — Click a timeline milestone's calendar icon; verify the `.ics` file downloads.
5. **Reset** — Click "Start over" (if present) or navigate to `/plan/new`. Confirm localStorage clears.

---

## Accessibility checkpoints (run during any flow)

- [ ] Tab through the entire wizard — every field and button reachable, focus ring visible.
- [ ] Skip-to-content link appears on first Tab press.
- [ ] Screen reader: headings announce correctly, form errors are announced, live region speaks plan status.
- [ ] Zoom to 200% — no horizontal scroll, no clipped content.
- [ ] `prefers-reduced-motion` — disable animations; verify no transitions > 0ms.

## Source badge

- Plans generated by AI show "AI-generated" badge.
- Plans from the local fallback (no API key / offline) show "Template" badge.
