# Decisions & Deviations Log

This log records (a) architectural decisions beyond PRD Appendix B, and (b)
every place the **installed** library differs from the API the PRD assumed.
Per PRD §0.7 we follow the installed library's current docs; behaviour,
contracts and security rules in the PRD still apply.

## Deviations from PRD-assumed versions

| # | Area | PRD assumption | Installed | Impact / action |
|---|------|----------------|-----------|-----------------|
| V1 | Next.js | App Router (≈15) | **16.4.3** | App Router API compatible. Experimental `cacheComponents`/`partialPrefetching` that the scaffolder enabled are **disabled** in `next.config.ts` — they force explicit cache/`connection()` boundaries that conflict with per-request cookie auth in Server Components. |
| V2 | React | 19.x | **19.3.0** | No change. |
| V3 | Tailwind CSS | v4 (CSS-first `@theme`) or config fallback | **v4.3** | CSS-first used: tokens in `src/styles/tokens.css`, mapped via `@theme inline` in `globals.css`. No `tailwind.config.ts`. |
| V4 | Zod | v3-style | **v4.6** | `z.string().email()` → `z.email()`, `z.string().url()` → `z.url()`, errors formatted with `z.prettifyError()`. `z.infer` single-source types still apply (§25.1). |

| V6 | firebase-admin | v12/13 | **v14** | `initializeApp`/`cert`/`getAuth`/`getFirestore` unchanged. |

| V8 | maplibre-gl | v4/v5 | **v6** | Verify `Map`, `GeoJSONSource`, heatmap layer API against v6 docs before use (T-13). |

| V10 | Testing | Vitest/RTL/Playwright | **Vitest v5**, Playwright, RTL | No change expected. |

## Design / implementation decisions

| # | Decision | Rationale |
|---|----------|-----------|
| D-impl-1 | **shadcn/ui primitives are hand-authored** on Radix + `class-variance-authority`, restyled to `--cp-*` tokens, rather than generated by the shadcn CLI. | Full control over tokens, guarantees the "no raw hex in components" lint (§44), avoids CLI output tuned for a different theme. Still shadcn-compatible structure. |
| D-impl-2 | Env split into `src/lib/env.ts` (NEXT_PUBLIC, static refs for inlining) and `src/lib/server-env.ts` (`server-only`, lazy+cached validation). | Importing a module must not crash a credential-less build; first runtime use fails fast (§40). |
| D-impl-3 | Gemini model IDs (`gemini-3.8-flash`, etc.) are **config, not hardcoded**, and will be verified against the live models page before T-09 ships. | PRD is dated after the model knowledge cutoff; follow the live API (§0.7). |
