# Accessibility (WCAG 2.2 AA)

PlanPop targets Lighthouse Accessibility 100 and axe-core 0 violations (light + dark, desktop +
mobile). This document holds the manual checklist; automated checks run in Playwright.

## Automated

- axe-core runs on every route via Playwright, in light and dark, desktop and mobile viewports.
- `eslint-plugin-jsx-a11y` enforces accessible JSX at lint time.

## Manual checklist

- [ ] Semantic landmarks: one `header`, `nav`, `main`, `footer`; single `h1` per page.
- [ ] Logical heading order; no skipped levels.
- [ ] Skip-to-content link; visible focus on every interactive element (4px dashed outline).
- [ ] Full keyboard operation incl. tabs (`role="tablist"`, arrow keys), no drag-only actions.
- [ ] Form labels always visible; `aria-describedby` for hints/errors; `aria-invalid` on error;
      error summary receives focus on submit.
- [ ] AI output region `aria-live="polite"`; loading state `aria-busy`.
- [ ] Charts: `role="img"` + `aria-label` summary + visually-hidden data table.
- [ ] Touch targets ≥ 44×44 px; zoom to 200% without loss of content.
- [ ] `lang="en"` on `<html>`.
- [ ] Status never conveyed by colour alone (icon + text always accompany colour).
- [ ] Motion limited to 150 ms transforms; disabled under `prefers-reduced-motion`.
- [ ] Contrast ≥ 4.5:1 for text (black text on all coloured fills).
